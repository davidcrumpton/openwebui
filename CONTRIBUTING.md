# Contributing

**No contributions are currently accepted.**

This fork is a mirror of the official [OpenWebUI](https://github.com/open-webui/open-webui) repository. Since the upstream project maintains the best tools, features, and community support directly there, please submit issues and pull requests to the official OpenWebUI repository instead:

- **Official Repository:** https://github.com/open-webui/open-webui
- **Community Issues:** https://github.com/open-webui/open-webui/issues

## Why not contribute here?

1. **Upstream Support** - The official project receives active maintenance and feature development from the core team
2. **Better Tooling** - Official repositories have mature CI/CD, comprehensive documentation, and established workflows
3. **Community Impact** - Your contributions will reach a wider audience through the main project
4. **Feature Priority** - Major enhancements are prioritized in the upstream repository

## If you'd like to help

- Open an issue or pull request at [https://github.com/open-webui/open-webui](https://github.com/open-webui/open-webui)
- Join the community discussions on GitHub Discussions or other official channels
- Share your improvements there so they can be merged into the main codebase

Thank you for your interest! Your support of the open-source ecosystem is appreciated.
