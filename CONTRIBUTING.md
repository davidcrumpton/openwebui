# Contributing to OpenWebUI Custom Tools

## None Allowed

This repository is intentionally maintained as a collection of custom tools for use with OpenWebUI. However, **no contributions are accepted**.

### Why?

The official OpenWebUI project already contains superior versions of all code herein. This repository serves as a personal workspace/experimental branch rather than a canonical implementation.

- All functionality is already implemented and improved in the upstream OpenWebUI repository
- Contributions would not be merged into this repo
- The official version should always be preferred for production use

### Purpose of This Repo

This repository exists to:
- Test custom tools using VS Code debugging and pytest
- Provide a sandbox for experimentation before upstreaming changes
- Store personal adaptations or experiments (which may eventually be merged upstream)

### Best Practice

When you need these tools, **use the official OpenWebUI repository** directly. The official version has:
- Better code quality
- More features
- Active maintenance
- Community support

### Exception

The only acceptable modifications to this repository are:
1. Internal testing artifacts
2. Personal experimental forks (not for public use)

**Pull requests, issue reports, or feature requests regarding contributions will be closed without consideration.**
