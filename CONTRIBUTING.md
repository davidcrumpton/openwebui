# CONTRIBUTING

## ❌ Contributions Not Accepted

This repository does **not accept contributions** or pull requests.

### Why?

This repository contains custom tools designed for Open WebUI, but these are personal/utility tools rather than improvements to the core project. The official [Open WebUI repository](https://github.com/open-webui/open-webui) already provides superior, actively-maintained versions of all features implemented here.

### What This Repo Is For

- **Personal development workspace** for custom Open WebUI tool integrations
- **Testing ground** for experimenting with MCP-based tools
- **Reference implementation** for specific use cases (Home Assistant, Zabbix, GitLab, Wiki.js, etc.)

### Why Not Contribute?

1. **Official Maintainers Have Priority** - The Open WebUI team maintains the official codebase with proper CI/CD, testing, and community review
2. **Fork vs Core Separation** - Custom tools are better as local forks or separate integrations rather than merged into core
3. **Active Development Elsewhere** - Features you see here have already been implemented or are in progress in the official repo
4. **Maintainer Bandwidth** - The Open WebUI maintainers handle issues, PRs, and roadmap prioritization

### If You Want to Contribute...

Instead of contributing to this repository:

- ✅ Submit your improvements directly to the [official Open WebUI GitHub](https://github.com/open-webui/open-webui)
- ✅ Create your own fork with customizations
- ✅ Open issues in the official repo for feature requests
- ✅ Follow their [contribution guidelines](https://github.com/open-webui/open-webui/blob/main/CONTRIBUTING.md)

### Thank You!

Thanks for reading! If you found these tools useful, feel free to:
- Star or fork this repo if it helped with your project
- Check out the official Open WebUI for production use
- Report any issues specific to my custom implementations here
