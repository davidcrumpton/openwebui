# Contribution Guide

## ❌ No Contributions Allowed

**Contributions are not accepted.**

This repository contains custom tools designed for Open WebUI. However, you should use the official OpenWebUI repository instead, as it provides **superior, well-supported versions** of this functionality with active maintenance and community support.

### Why?
- The official OpenWebUI repo offers production-ready implementations
- Actively maintained by the core team with security updates
- Better integration with official OpenWebUI features
- Community-tested and reviewed codebase

### What to do instead:
1. Use the [official OpenWebUI repository](https://github.com/openwebui)
2. Report issues or feature requests there
3. Contribute to their main project where your work will be utilized
